# Luna Sync 用户协议 / User Agreement

**生效及更新日期 / Effective and last updated: 2026-07-22**

## 1. 服务说明 / Service Description

Luna Sync 是开源的本地相机素材备份与管理工具，用于连接用户有权使用的 Luna 相机，并在用户自己的设备上扫描、预览和下载素材。本应用与 Insta360（影石）不存在官方授权、合作或隶属关系。

Luna Sync is an open-source, local camera media backup and management tool for cameras the user is authorized to access. The app is not officially authorized by, affiliated with, or endorsed by Insta360.

## 2. 使用条件 / Acceptable Use

用户应仅连接本人拥有或获授权访问的相机和网络，不得利用本应用访问、复制或破坏他人数据。用户应自行确认无线网卡、NAS、Docker 与相机固件的兼容性，并对网络环境和备份目录权限负责。

Use the app only with cameras and networks you own or are authorized to access. Do not use it to access, copy, or damage another person's data. Users are responsible for device compatibility, network configuration, and media directory permissions.

## 3. 数据目录与删除风险 / Data Directory and Deletion Risk

安装时必须选择素材保存目录。请新建并使用 Luna Sync 专用目录，不要将个人文件、其他应用数据与 Luna Sync 数据混存。执行删除、清理、重新挂载或卸载操作前，请确认目录内容并保留必要备份。

Select a media folder during installation. Create and use a dedicated Luna Sync folder and do not mix personal files or other application data with Luna Sync data. Review the directory and keep necessary backups before deleting, cleaning, remounting, or uninstalling.
