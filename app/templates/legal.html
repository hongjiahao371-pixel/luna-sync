2. 处理的信息

Luna Sync 在用户自己的 NAS 或电脑中本地处理：Web 访问密码（首次使用时由您设置，仅以 PBKDF2 加密哈希保存在本机状态目录，用于验证登录，不保存明文）；相机 Wi-Fi 名称与密码（仅自部署版本提供应用内 Wi-Fi 管理并加密保存；应用商店版本已彻底移除应用内 Wi-Fi 表单与扫描功能，不收集 Wi-Fi 名称与密码，请在系统 Wi-Fi 设置中连接相机）；无线网卡状态、相机媒体目录、下载进度、缩略图和兼容预览缓存。应用不收集账号、手机号、精确位置、通讯录或支付信息。

3. 处理目的与范围

Wi-Fi 凭据仅用于连接用户选择的 Luna 相机；媒体目录仅用于展示、预览和增量备份；运行状态与缓存仅用于恢复任务和提升预览速度。上述信息仅在用户自己的设备和局域网中处理，不会发送给开发者，也不会上传到云端或第三方。

6. 保存位置与期限

  • Wi-Fi 名称与密码经加密保存在应用状态目录，直至用户点击“清除记住”、撤回授权、清除应用数据或卸载应用。

7. 用户权利及行权途径

  • 访问：应用内即可查看全部被处理的数据——素材库、下载记录、设置与缓存均在界面中呈现。
  • 更正：可在应用内修改 Wi-Fi 配置（自部署版）与素材目录；如需更正访问密码，可通过“撤回授权”后重新初始化。
  • 删除：可在应用内“清除记住的 Wi-Fi”“清除缓存”、删除素材或选片记录；卸载应用即删除全部应用状态数据（素材目录中的文件除外，由用户自主管理）。
  • 撤销同意：点击下方“撤回授权”，或通过联系方式提出。撤回后应用将清除同意记录、Web 访问密码、登录会话、已保存的 Wi-Fi 凭据及缓存，回到首次使用状态，并停止一切数据处理。
  • 注销账号：本应用不提供账号注册服务，无账号注销事项；卸载应用即等同于删除全部本地数据。

将清除同意记录、访问密码、登录会话、已保存的 Wi-Fi 凭据、选片/相册记录与缓存；素材目录中的文件不会被删除。操作后需重新授权方可继续使用。

8. 用户控制与安全

用户可随时清除记住的 Wi-Fi、预览缓存及已下载素材。Wi-Fi 凭据以加密形式存储，文件权限设置为仅应用运行用户可读写；对素材与缓存文件的访问经路径合法性校验，不跟踪符号链接。Web 管理界面默认通过 HTTPS（TLS）加密传输，登录密码、Wi-Fi 凭据等信息均在加密通道中传输，会话 Cookie 仅经加密通道发送。请仅在可信局域网内使用应用，并为素材选择独立目录，避免与其他个人数据混存。

Privacy Policy

Effective and last updated: September 25, 2026 (version 2026-09-25)

1. Operator

Luna Sync is developed and operated by the individual developer jvsheng (hongjiahao371-pixel). The operator has no corporate entity or registered business address; the operator's real identity has been verified and is disclosed by the UGREEN App Center on the app detail page as required by the platform. Personal information protection contact: jvsheng — 1981940361@qq.com or GitHub Issues.

2. Information Processed

Luna Sync locally processes: the web access password (set by you on first use and stored on the device only as a PBKDF2 hash for login verification; the plaintext is never saved); the camera Wi-Fi SSID and password (self-hosted deployments only, stored encrypted — the store-distributed version has fully removed the in-app Wi-Fi form and scanning feature and does not collect Wi-Fi information; connect the camera in your system Wi-Fi settings instead); wireless adapter status, camera media listings, download progress, thumbnails, and compatible preview cache. It does not collect accounts, phone numbers, precise location, contacts, or payment information.

3. Purpose and Scope

Credentials are used only to connect to the selected Luna camera. Media listings are used only for browsing, preview, and incremental backup. This information stays on the user's device and local network and is not sent to the developer, cloud services, advertisers, or analytics providers.

4. List of Personal Information Collected

  • Web access password — login verification; PBKDF2 hash stored locally, never the plaintext; kept until withdrawn or app data is cleared.
  • Camera Wi-Fi SSID and password — self-hosted deployments only, encrypted at rest; not collected by the store version; kept until cleared or withdrawn.
  • Camera media listings — browsing, preview, incremental sync; processed in memory and local state files.
  • Downloaded media — stored in the folder you selected; deleted only by you.
  • Thumbnail and preview cache — stored locally until cleared or withdrawn.
  • Settings and consent record — stored locally until app data is cleared.

5. List of Third-Party Sharing

None. The app does not share, transfer, or disclose personal information to any third party, and integrates no advertising, analytics, statistics, or telemetry SDK — there is no channel that uploads user data to the developer or any cloud service.

6. Storage and Retention

Wi-Fi credentials are stored encrypted in the app state directory until cleared or withdrawn. Settings and consent records remain until app data is removed. Preview cache remains until cleared. Downloaded media remains in the chosen folder until the user deletes it; uninstalling the app does not remove that external media folder.

7. Your Rights and How to Exercise Them

  • Access: all processed data (library, downloads, settings, cache) is visible inside the app.
  • Correction: Wi-Fi settings (self-hosted) and the media folder can be changed in the app; the access password can be reset by withdrawing consent and re-initializing.
  • Deletion: clear saved Wi-Fi, cache, media, and curation records inside the app; uninstalling removes all app state (files in your media folder are kept for you to manage).
  • Withdrawal of consent: use the "Withdraw consent" action below or contact us. Withdrawing clears the consent record, web password, sessions, saved Wi-Fi credentials, and caches, returns the app to its first-run state, and stops all processing.
  • Account deletion: not applicable — the app has no account system; uninstalling deletes all local data.

8. Security

Wi-Fi credentials are stored encrypted with permissions restricted to the app runtime user; file access is path-validated and does not follow symbolic links. The web console is served over HTTPS (TLS) by default, so the login password and Wi-Fi credentials are transmitted through an encrypted channel, and the session cookie is only sent over that secure channel. Use the app only on a trusted local network and select a dedicated Luna Sync media folder.

9. Cross-Border Transfer

All personal information is stored and processed only on the user's own device. The app has no cloud service and does not transfer personal information across borders. Migrating the media folder or app data to an overseas server by yourself is a user action unrelated to the app.

10. Children's Information

The app is a camera media backup tool for general users. It is not directed at children, does not knowingly collect children's personal information, and has no account registration. If you believe a child's information was processed unintentionally, contact us through the channels above and we will delete it promptly.

11. Policy Updates

Material changes to this policy will be presented in-app for your consent again; the current version is always available under "Privacy & Terms" in the app. You may withdraw consent if you do not accept an updated policy.
